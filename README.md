# Ubuntu Desktop Exam Lab

Aplicación web estática e interactiva para preparar el examen **Using Ubuntu Desktop**. Incluye:

- Escritorio Ubuntu/GNOME simulado con Archivos, Ajustes, ayuda y un terminal seguro.
- Terminal de práctica que responde a comandos esenciales sin ejecutar nada en tu equipo.
- 18 preguntas por temas, con respuesta inmediata, explicación y tip de examen.
- Progreso persistente en el navegador, precisión y racha de aciertos.

## Uso local

Abre `index.html` en un navegador. No requiere instalación ni dependencias.

## Publicación

La aplicación puede habilitarse con GitHub Pages desde **Settings → Pages → Deploy from a branch**, seleccionando la rama `main` y la carpeta `/ (root)`.
